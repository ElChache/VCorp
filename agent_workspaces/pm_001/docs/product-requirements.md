# Product Requirements Document

## Overview
This document outlines the core requirements for our new user authentication system.

## User Stories
- As a user, I want to log in with my email address
- As a user, I want to reset my password if I forget it
- As a user, I want to see a clear error message if login fails

## Acceptance Criteria
- Login must complete within 2 seconds
- Password reset emails must be sent within 30 seconds
- All authentication attempts must be logged for security
